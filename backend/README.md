# LinkNGo Backend - Phase 1

This is the backend foundation for the LinkNGo project. It currently includes a basic Express server setup with a single health check endpoint.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set up environment variables:
   Copy `.env.example` to `.env`.

## Run

- Development mode: `npm run dev`
- Production mode: `npm start`
